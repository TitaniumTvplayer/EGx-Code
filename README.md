# إشارات البورصة المصرية (EGX Signal)

تطبيق أندرويد بسيط (WebView) بيجيب بيانات الأسهم المصرية، ويحسب RSI وMACD والمتوسطات وحجم التداول، ويعرض لك "المؤشرات بتقول إيه" لكل سهم. مش توصية مالية.

## بناء الـ APK على GitHub
1. اعمل repository جديد على GitHub.
2. ارفع كل محتويات المجلد ده (مع المجلد المخفي `.github`) على الفرع `main`.
3. افتح تبويب **Actions** وستلاقي Workflow اسمه **Build APK** بيشتغل لوحده (أو اضغط Run workflow).
4. لما يخلص، افتح التشغيل ونزّل الـ artifact اسمه `egx-signal-apk`، جواه `app-debug.apk`.
5. انقله للموبايل وثبّته (هيطلب السماح بالتثبيت من مصدر غير معروف).

## مصدر البيانات
- الأساسي: Yahoo Finance (شموع يومية، بدون مفتاح). الأكواد المصرية بتتحول تلقائي لصيغة `COMI.CA`. المصدر غير رسمي وممكن يتأخر أو يتغير.
- اختياري: مفتاح Oanor من الإعدادات عشان يظهر السعر اللحظي بدل آخر شمعة.

## تعديل القائمة الافتراضية
في `app/src/main/assets/index.html` ابحث عن `DEFAULTS`.
